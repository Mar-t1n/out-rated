Credits & Info

Out-Rated! is a movie comparison game where you test your cinema expertise by identifying which film rated higher on TMDB.

Technologies Used

  • HTML5 & Semantic Elements
  • Vanilla CSS (Custom CSS Variables, Keyframes, Glassmorphism)
  • Vanilla JavaScript (Modern async actions)
  • Node.js backend for serving assets and API caching

This product uses the TMDB API but is not endorsed or certified by TMDB.

Developed with ❤️ as a modern interactive web experience.
